# 统一制作标准：pixel-144-24-v1

这是本技能的默认制作合同。图像提示、帧表、验收和导出共用这一份规格；脚本常量在 `scripts/standard.mjs`。用户明确改变规格时才使用 `profile: "custom"` 并记录原因，不能为了迁就失败序列改变帧数或角度。

| 项目 | 固定标准 |
| --- | --- |
| 成品 | 144×144 PNG 帧和透明 GIF，硬 alpha、最近邻采样 |
| 整圈 | 24 个真实不同的旋转方向，F01…F24；文件编号仍是0000…0023 |
| 角度目标 | 第 i 帧（i从0起）为15i°，0…345°，不另加360° |
| 方向 | 正面 → 鼻尖朝画面左 → 正背 → 鼻尖朝画面右 → 正面 |
| 时间 | 每帧80ms，12.5fps，一圈1.92秒，无停留帧、无快慢帧 |
| 原画 | 纯二维像素绘制，静态紧凑坐姿，不带弹跳、压扁、眨眼或头发飘动 |
| 姿态 | 接近二头身；头顶到下巴约为坐姿可见高度的55%–65%（不计拖尾头发）；短脚收拢、手垂髋侧 |
| 身份 | 已接受的正面像素母版为全圈外观依据；原设定为神态、配饰、左右差异依据 |
| 调色板 | 整圈共用最多48个含透明槽的色板项；不逐帧调色 |
| 转轴／底线 | 144网格x=72，底线y=137；按头颅/躯干轴登记，不用轮廓质心 |
| 安全空间 | 整圈共用0.045的边距比例，预留最大1.5倍横向拉伸，不能逐帧单独裁边 |
| Q弹 | 每圈2次，纵向2/3…1，横向1…1.5，围绕固定坐姿底线缩放 |

**15°是绘制目标，不是可从普通二维图自动精确测出的角度。** 画面必须显示小步、同方向、速度近似均匀的转身；标签正确不能替代验收。不能声称提示词保证了精确角度。

## 一张帧必须与邻帧有什么关系

1. 头、躯干和坐姿一起绕同一竖直轴转；只能因转向改变显露/遮挡，不允许独立扭头或手脚动作。
2. A→M→B三张的中间帧M必须视觉上位于A、B之间。A→M和M→B都应有小幅推进，不能一边几乎不动、另一边大跳。
3. 用脸颊/耳朵/鼻尖与眼睛显露，配合肩袖/前胸图案/手脚/裙摆的投影与遮挡共同判断。头发纹理、光泽、衣褶重画不算转向。背面看不到胸时，记录可见侧袖、手、裙摆等；不可编造被遮住的证据。
4. 正侧、正背、正面锚点仅在对应位置达到，邻帧不能提前复制。F24→F01和F01→F02必须像其他相邻对一样推进。
5. 每帧方向判断使用同一尺度、转轴、底线的无Q弹图。相邻差值、文件哈希仅用来定位可疑段，不能用像素变化量当角度。

## Q弹定义

先让纯旋转通过，再对每个源帧只做一次缩放：

```text
N = 24, i = 0…23
sy(i) = 5/6 + (1/6) cos(4πi/N)
sx(i) = 1 / sy(i)
目标像素围绕 (72,137) 最近邻反向采样；不平移底线。
```

这采用横竖面积近似守恒的夸张弹性，不是物理体积模拟。中性原画是最高状态，压扁时最矮为2/3、最宽为1.5倍；不增加多余方向帧，也不平滑/混合相邻角色图。

| 用户帧 | 目标角 | 高度sy | 宽度sx | 状态 |
| --- | --- | --- | --- | --- |
| F01 | 0° | 1 | 1 | 最高 |
| F04 | 45° | 5/6 | 1.2 | 压缩途中 |
| F07 | 90° | 2/3 | 1.5 | 最扁 |
| F10 | 135° | 5/6 | 1.2 | 回弹途中 |
| F13 | 180° | 1 | 1 | 最高 |
| F16 | 225° | 5/6 | 1.2 | 压缩途中 |
| F19 | 270° | 2/3 | 1.5 | 最扁 |
| F22 | 315° | 5/6 | 1.2 | 回弹途中 |

F24仍未到最高，接F01自然闭合。原尺寸栅格取整允许轮廓一像素变化，转轴和底线坐标不变。所有方向共同决定可容纳的中性大小；不能为了填满画布把宽方向单独缩小。

运行 `node scripts/standard.mjs /path/to/job/frame-plan.json` 创建完整24帧目标、邻接、补画端点、时间和缩放表。该表是计划，不是质量通过记录。
