# 验收：先检查姿态，再检查完整动画

## 自动检查能证明什么

`validate` 检查两个尺寸的文件数量、尺寸、每帧时长、无限循环标记和透明掩码，检查所有 PNG 是否触碰画布边界。它不评价角色身份、真实转身角度、坐姿美观或补间自然程度。

`poseOnlyDifferences` 包含每一对相邻帧以及末帧→首帧。近乎重复帧与高于中位值的差异会被标记为 reviewFlags；它们是检查入口而非自动判废条件。遮挡本身可能导致合法变化，微小像素差也可能掩盖错误方向。

## 必须实际看的内容

1. **完整循环**：至少观看三圈，确认前后半圈同方向、同角色、没有“停—跳—停”。查看 512 和 256 两个尺寸的实际显示效果。
2. **静态登记图**：头、躯干的轴线一致，坐姿接触点不漂移；不能用尾巴移动造成的质心变化来移动角色。
3. **重点区间**：后侧到正背、正背到另一侧、侧面回正面、末尾到开头。遇到问题查看 `pose-only/`，排除 Q 弹对差值的影响。
4. **Q 弹**：明显变扁变高，变扁时宽度相应增加，坐姿底线保持稳定；不依赖整个人上下漂移来制造弹性感。
5. **细节**：左右不对称部件不能镜像换侧；被遮挡部件不能忽隐忽现；嘴眼、发梢、头饰不能双影或熔化。
6. **导出**：在浅色／深色背景各看一次，确认没有黑边、白边、棋盘背景或上一帧残留。母版透明度不能为迁就 GIF 而被破坏。

## 留下诚实的结果

实际完成检查后，在产物旁写简短 `visual-review.md`，列出检查的文件、异常区间和是否修补；仅此时才将产物报告里的 `visualReview` 改为 `passed` 或 `needs-repair`。工具不代替观察自动填写通过。

高分辨率素材如果只是重复使用小图或放大旧图，不能作为清晰度验收通过。高帧数也不能作为旋转连贯性的证据。

同类局部修补两轮仍无改善时，记录限制并保留可用版本，再判断补画更多关键姿态或调整目标；不要无限堆叠插值。
