# 朋友的酒（DJ版）· 欧耶耶！144px 像素弹转梗图

**欧耶耶！开心比什么都贵！把你的角色也做成坐着 Q 弹转圈的那个梗。**

`chibi-squash-spin` 是一个 Codex 玩梗技能：从人物设定图制作接近二头身、短腿收拢、双手垂在身体两侧的 **144×144 像素风坐姿角色**。先直接绘制整圈连续旋转序列并验收，再通过横竖缩放加入 Q 弹，输出透明循环 GIF。

适合「朋友的酒旋转梗」「欧耶耶表情包」「开心比什么都贵」「像素 Q 弹旋转 GIF」「坐姿转圈梗图」。[Bilibili 动作参考：昨日一去不复回❌～欧耶耶！开心比什么都贵](https://www.bilibili.com/video/BV1tRaH6oET9/)。搭配的 BGM 为《朋友的酒（DJ版）》；GIF 无音轨，本技能不附带歌曲或默认对拍。

## v2 的制作方法

- 正面先过关：二头身、短脚、双手位置、原人物眼神与神态，不能统一变成甜笑。
- 默认直接画 24 张不同的中性旋转方向，完整覆盖一圈；**一张旋转源图对应一张成品帧**。
- 先输出不带 Q 弹的旋转 GIF，观察通过后才添加弹性。缺朝向或转身跳变回到原图修补。
- 不使用少数朝向反复压扁、最近纹理切换、镜像凑帧或融化补间。
- 最近邻采样、全圈共享有限调色板；默认 144px，保留 PNG 源帧及纯旋转版本。

旧版的 12 朝向＋60 帧补间及 256/512 高清默认值已被替换；旧配置需要先补齐直接旋转序列。当前默认 24 帧、每帧 80ms、一圈 1.92 秒、每圈两次 Q 弹；时长随实际源帧数变化。

## 安装与使用

需要 Node.js 22+、FFmpeg，以及 Codex 可用的内置图片生成工具。

```sh
git clone https://github.com/SSSimpleC/chibi-squash-spin.git ~/.codex/skills/chibi-squash-spin
cd ~/.codex/skills/chibi-squash-spin
npm ci
```

附上设定图后输入：

> 使用 $chibi-squash-spin，保留这位角色的眼神和神态，制作二头身、短脚收拢、双手垂在两侧的144px像素风坐姿。先直接生成完整连续旋转序列，检查纯旋转，再添加《朋友的酒（DJ版）》欧耶耶梗的Q弹。

流程见 [SKILL.md](SKILL.md)，配置和命令见 [pipeline](references/pipeline.md)，验收标准见 [quality](references/quality.md)。脚本不会自行生成角色，也不会修改 RunCat。

## 检查

```sh
npm test
node scripts/spin.mjs --help
```

测试覆盖直接帧对应、拒绝稀疏／重复朝向、纯旋转验收门槛、修改后重新检查、像素调色板、硬透明度与 GIF 残影。它们不证明某个生成角色已通过视觉验收。用户原图与生成素材不包含在仓库中。
